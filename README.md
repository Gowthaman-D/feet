# RATIO - Financial Tracker

A complete frontend-only **RATIO** web application built exclusively with **HTML5** and **CSS3**.

## Requirements Met
- **Zero JavaScript**: Built with 100% pure HTML5 and vanilla CSS3.
- **No Frameworks**: No React, Tailwind, Bootstrap, or external CSS libraries.
- **Fully Static**: Ready to run directly in any web browser without build tools or a backend server.
- **Modern Banking UI**: Features a royal blue and white color scheme, rounded glassmorphism navigation, CSS micro-animations, and responsive grid/flexbox layouts.

## Project Structure
```
expense-tracker/
│── login.html        # Centered login card with HTML5 validation
│── dashboard.html    # Financial overview, summary cards, and recent transactions
│── add.html          # New transaction form with custom radio selectors & dropdowns
│── history.html      # Complete 12-transaction ledger with status badges
└── style.css         # Shared design system and stylesheet
```

## How to Run
1. Open the `expense-tracker` folder.
2. Double-click `login.html` to open it in your browser.
3. Enjoy the seamless HTML-only navigation and responsive financial tracking experience!
